Thư mục này dùng để chứa các file poster của phim.

Đặt ảnh poster vào đây với tên file tương ứng trong data.json, ví dụ:
- inception.jpg
- interstellar.jpg
- darkknight.jpg
- breakingbad.jpg
- got.jpg
- strangerthings.jpg
- endgame.jpg
- witcher.jpg

Định dạng khuyến nghị: JPG hoặc WEBP, tỷ lệ 2:3 (poster dọc), ví dụ 300x450px.

Nếu không có ảnh, website sẽ hiển thị placeholder tự động.
